# QuickCart Week 1
Synthetic online retail data for a beginner data engineering lab.
Use Python 3.11. Follow Week1_Student_Lab.docx for platform-specific setup.
Write code in explore.py, run commands in the VS Code terminal, and record findings in data_issues.md.
Run python generate_data.py, then python explore.py from this project folder.
Do not edit the generator or source data. The generator intentionally includes quality problems.
The data folder and virtual environment are ignored by Git. Data can be regenerated.
The initial repository has six files including .gitignore; data/ and .venv/ appear during the lab.
Cloning creates a local copy with history. Your Week 1 commit stays local unless you later push to a repository you own.
